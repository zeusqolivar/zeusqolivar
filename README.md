### 🧠 How I build

- Modern Swift concurrency: `async/await`, actors, `@MainActor`, `@Observable`
- Protocol-oriented, testable architecture: MVVM, Clean Architecture, SOLID
- SwiftUI first, UIKit + RxSwift + SnapKit where it fits, and the migration path between them
- On-device AI with Apple's **Foundation Models**, privacy-first, no-account apps
- End-to-end ownership: backend (Supabase, Firebase), payments (StoreKit 2, Maya), CI/CD (Fastlane), App Store release
